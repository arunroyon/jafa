JAFA — JWST Aromatic Feature Analyzer
=====================================

JAFA — JWST Aromatic Feature Analyzer creates continuum-subtracted spectral
feature maps and ratio maps from JWST IFU cubes. The current focus is MIRI MRS
PAH and fullerene science, with the code structured so NIRSpec IFU support can
be added without rewriting the analyzer.
