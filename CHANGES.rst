Changes
=======

0.1.0
-----

- Renamed the project to JAFA — JWST Aromatic Feature Analyzer.
- Initial package structure for JWST IFU spectral feature mapping.
- Added YAML feature database for PAH and fullerene features.
- Added morphology-plus-spline continuum fitting.
- Added feature-map and ratio-map workflows with FITS, metadata, and diagnostic outputs.
- Added lazy optional dependency loading for JWST cube support, reprojection, and plotting.
